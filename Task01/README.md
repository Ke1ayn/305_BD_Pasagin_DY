# Описание данных

В каталоге находятся исходные данные, используемые для выполнения лабораторных работ по курсу "Базы данных". Формат соответствует набору данных MovieLens (расширенному дополнительными файлами о пользователях).

## ratings.csv — оценки фильмов

CSV, разделитель `,`, первая строка — заголовок. 18773 строки с данными.

| Столбец   | Тип          | Описание                                                                 |
|-----------|--------------|---------------------------------------------------------------------------|
| userId    | целое        | Идентификатор пользователя. Диапазон: 1–120.                              |
| movieId   | целое        | Идентификатор фильма. Диапазон: 1–190183.                                 |
| rating    | вещественное | Оценка фильма от 0.5 до 5.0 с шагом 0.5.                                   |
| timestamp | целое        | Время оценки в формате Unix time (секунды с 1 января 1970 года).          |

## movies.csv — фильмы

CSV, разделитель `,`, первая строка — заголовок. 9742 строки с данными.

| Столбец | Тип    | Описание                                                              |
|---------|--------|--------------------------------------------------------------------------|
| movieId | целое  | Идентификатор фильма.                                                    |
| title   | строка | Название фильма и год выпуска в скобках.                                 |
| genres  | строка | Список жанров фильма, разделённых символом `\|` (значения из genres.txt). |

## tags.csv — теги, проставленные пользователями фильмам

CSV, разделитель `,`, первая строка — заголовок. 3683 строки с данными.

| Столбец   | Тип    | Описание                                            |
|-----------|--------|--------------------------------------------------------|
| userId    | целое  | Идентификатор пользователя, поставившего тег.           |
| movieId   | целое  | Идентификатор фильма.                                   |
| tag       | строка | Текст тега (произвольная метка, заданная пользователем).|
| timestamp | целое  | Время в формате Unix time.                              |

## users.txt — пользователи

Текстовый файл, разделитель полей — `|`, без заголовка. 943 строки (одна на пользователя).

| № поля | Название           | Описание                                       |
|--------|---------------------|-------------------------------------------------|
| 1      | userId              | Идентификатор пользователя.                     |
| 2      | name                | Полное имя пользователя.                        |
| 3      | email               | Электронная почта.                              |
| 4      | gender              | Пол (male/female).                              |
| 5      | registration_date   | Дата регистрации в формате ГГГГ-ММ-ДД.          |
| 6      | occupation          | Род занятий (значение из occupation.txt).       |


## genres.txt — справочник жанров

Текстовый файл, по одному жанру на строке. 18 значений (Action, Adventure, Animation, Children's, Comedy, Crime, Documentary, Drama, Fantasy, Film-Noir, Horror, Musical, Mystery, Romance, Sci-Fi, Thriller, War, Western). Используется как справочник допустимых значений для столбца `genres` в `movies.csv`.

## occupation.txt — справочник профессий

Текстовый файл, по одной профессии на строке. 21 значение (administrator, artist, doctor, educator, engineer, entertainment, executive, healthcare, homemaker, lawyer, librarian, marketing, none, other, programmer, retired, salesman, scientist, student, technician, writer). Используется как справочник допустимых значений для столбца `occupation` в `users.txt`.
